# ADR-0013: Secrets management and rotation

## Status

| Status | Date |
|---|---|
| Decided | 2026-10-29 |

## Priority

Should

## Question

How are application secrets stored, delivered to the API and rotated?

## Why it matters

A secret injected into a container as an environment variable is read only at start-up, so after a rotation a running task keeps the old value until it is replaced by a new deployment. RDS can manage and rotate its master password itself. Terraform state holds any secret value Terraform creates.

## Sub-decisions

| # | Sub-decision | Options | Position | Status | Date |
|---|---|---|---|---|---|
| a | Store | AWS Secrets Manager; Systems Manager Parameter Store | Secrets Manager, for its rotation support and RDS integration | Decided | 2026-10-29 |
| b | Delivery of static secrets | Injected as environment variables at task start; fetched by the application | Injected at task start | Decided | 2026-10-29 |
| c | Database credentials for the API | A password injected at task start, so rotation needs a redeployment; a password the API fetches from Secrets Manager at connection time with a short cache; IAM database authentication | Fetched at connection time with a short cache. IAM database authentication is assessed against its connection limits before it is adopted. | Decided | 2026-10-29 |
| d | Rotation | Manual; scheduled rotation in Secrets Manager, with RDS-managed rotation for the master password | Scheduled rotation at the configured period ([C-15](../docs/configuration-defaults.md#c-15)) | Decided | 2026-10-29 |
| e | Encryption keys | AWS-managed keys; customer-managed KMS keys | AWS-managed keys by default, with a customer-managed key as an input ([C-15](../docs/configuration-defaults.md#c-15)) | Decided | 2026-10-29 |
| f | Secrets in Terraform | Generated by Terraform and stored in state; created by AWS services and only referenced by Terraform | Created by AWS services, such as RDS-managed passwords. No secret value is generated by Terraform or held in its state. | Decided | 2026-10-29 |
